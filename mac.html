TinyNudge for Mac

Menu-bar mouse jiggler — free download

The website keeps the display awake. The Mac app nudges the real pointer a few pixels and back, then keeps the display from sleeping. One disk image for Apple Silicon and Intel. macOS 13 or later. Accessibility permission is required.

Download for Mac — free Download ZIP Install notes

Version 1.1.0. Universal Mac app. No account, license key, or payment.

Install

  1. Open the disk image and drag TinyNudge to Applications.
  2. If macOS says Apple could not verify the app, click Done (not Move to Trash). Double-click Open TinyNudge.command on the disk image, or in Terminal run xattr -cr /Applications/TinyNudge.app, then right-click TinyNudge → Open. If the disk image will not mount, use the ZIP instead.
  3. System Settings → Privacy & Security → Accessibility → enable TinyNudge.
  4. Click Start. A countdown shows the next nudge. Pick 15, 30, or 60 seconds.
