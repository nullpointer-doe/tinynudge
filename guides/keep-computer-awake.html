Guide

Keep your computer awake

People search “keep my computer awake,” “stop screen sleep,” and online mouse jiggler when a laptop dims during a long PDF, a lecture, or an export. TinyNudge’s website is built for that job. It uses the browser Screen Wake Lock API so the display stays on. You do not install software or enter an admin password.

How to keep the screen on in the browser

  1. Open the TinyNudge online mouse jiggler.
  2. Click Keep screen awake.
  3. Leave the tab available, or use picture-in-picture so the lock can survive a tab switch.

This is the same class of signal as leaving a video playing: the operating system is asked not to dim the panel. It is not the same as moving the system mouse.

When a webpage is not enough

Desktop Slack, Microsoft Teams, Zoom, and similar apps watch keyboard and mouse idle, not a wake lock. If those go Away while the screen stays bright, use the status guide and, on a Mac, TinyNudge for Mac — only where your workplace allows it.

Online mouse jiggler vs USB vs Mac app

Choose the browser tool when you cannot install anything. Choose a USB mouse jiggler on a locked-down Windows PC. Choose the Mac menu-bar app when you need a real pointer nudge on macOS 13 or later. Details: USB vs software vs browser.
