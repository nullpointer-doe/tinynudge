What is a mouse jiggler?

A mouse jiggler — sometimes sold as a mouse mover or mouse wiggler — is anything that stops a computer from concluding you have walked away. The operating system uses idle time to dim the panel, start a screensaver, lock the session, or park the machine. Chat apps layer a second clock on top of that and flip you from Available to Away.

People look for a mouse jiggler when they are reading a long specification, waiting on a render, presenting from a laptop that wants to sleep, or running a kiosk that should never show the lock screen. Those are legitimate power-management problems. Using one to misrepresent attendance at work is a policy issue; TinyNudge is not built as a way to hide from monitoring software.

Three forms

  • USB mouse jigglers plug in and look like a tiny HID mouse. The computer sees periodic movement. They work on most managed PCs because they need no installer.
  • Software mouse jigglers are Mac or Windows apps. On macOS they usually live in the menu bar and need Accessibility permission to move the pointer a pixel or two. They avoid another gadget and another battery.
  • Online mouse jigglers run in the browser. They can request a screen wake lock (and sometimes play silent audio) so the display stays on. They cannot inject operating-system mouse events.

Mouse jiggler versus auto clicker

A jiggler is about movement or wake. An auto clicker sends click events into a game, a form, or a stubborn UI. TinyNudge does not click. If you need repeated clicks, you want a different class of tool, and you should treat it with even more care around terms of service.

Is it legal?

Owning a mouse mover is generally legal. Using it at work can still violate an employment agreement, a timekeeping rule, or an acceptable-use policy. If you are on a corporate laptop, ask IT or your manager before you install anything or plug in a USB device. TinyNudge’s website needs no install; that does not make status spoofing an approved workplace practice.

Safety

Prefer tools you can inspect. A webpage that only uses documented browser APIs is a smaller surface than an unknown binary. A signed Mac app that asks only for Accessibility is a smaller surface than a driver. Download sources matter: random “free mouse jiggler” installers are a common malware vector.

TinyNudge’s online mouse jiggler runs in your tab. The Mac app is a separate menu-bar utility for real pointer nudges.
