Online mouse jiggler: keep the screen awake without installing software

An online mouse jiggler is a webpage that asks the browser to treat the session as active enough to keep the monitor on. You do not download an .exe or a .dmg. You do not need administrator rights. That is why people search for “mouse jiggler online,” “mouse mover no install,” and “keep computer awake in browser.”

TinyNudge’s browser tool uses the Screen Wake Lock API. If the lock is denied or unsupported, it can fall back to a near-silent audio oscillator so some browsers still treat the tab as media. Optional picture-in-picture keeps a tiny surface alive when you switch tabs.

What it can do

  • Reduce display sleep while you read, present, or wait on a long download.
  • Run on Windows, macOS, Linux, and ChromeOS in a current desktop browser.
  • Stop on a clock you set, so a session does not run overnight by accident.

What it cannot do

  • Move the operating-system pointer. Web pages are not allowed to fake HID mice.
  • Reset idle in desktop Slack, Microsoft Teams, Zoom, or Discord by itself.
  • Override a closed MacBook lid. Clamshell sleep is a hardware policy.

How to use it

  1. Open mousejiggle.app in Chrome, Edge, Safari, or Firefox.
  2. Select Keep screen awake. Confirm the wake-lock lamp if your browser shows a prompt.
  3. Leave the window restored. If you must switch tabs, use the background PiP control.

Browser notes

Wake Lock is most consistent in Chromium (Chrome and Edge). Safari has supported it since 16.4. Firefox coverage has improved but still varies by version. If a corporate profile blocks Wake Lock, the audio fallback may still help the panel stay on, or it may not — power policy can win.
