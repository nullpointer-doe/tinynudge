Privacy policy

TinyNudge’s online mouse jiggler runs in your browser using the Screen Wake Lock API, optional silent audio, and optional Picture-in-Picture. Session state never leaves your device. We do not require an account, and we do not record mouse coordinates, keystrokes, or screen contents.

Use the contact form for questions. Do not send passwords.

This static site is hosted on GitHub Pages. GitHub sees normal web logs (IP address, user agent) as with any website. If Google Analytics is configured for this site, we also see page paths and Mac-app download clicks (file name only), with IP anonymization. The contact form is delivered by Formsubmit so we can receive messages without publishing an inbox on the page. Formsubmit and we see the name, email, and message you submit. We do not run advertising. TinyNudge is not a tool for bypassing employer monitoring or security software.

TinyNudge for Mac is a free download. See TinyNudge for Mac.
