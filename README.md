# TinyNudge website

Public site for [mousejiggle.app](https://mousejiggle.app/). Static HTML only. Hosted on GitHub Pages.

The Mac app is a free download at `downloads/TinyNudge.dmg` (ZIP at `downloads/TinyNudge.zip`). Source lives in the private `tinynudge-mac` repo. Rebuild with `zsh mac/build.sh` and copy the new disk image here.
